# Evidence: what has actually run against Meta's live API

Reproduce: start the gateway (`uvicorn gateway.server:app --port 8766`) and the server (`npm start`), then
`node scripts/live-e2e.mjs`. It writes `docs/evidence/live-run.json`, `live-reel-poster.png` and `live-reel.mp4`.
The raw log of the run below is `docs/evidence/live-run.json` (timestamps included, no secrets).

## Live run, 4 Nov 2026 (one campaign, one product photo)

| Step | Meta model | Result |
|---|---|---|
| Product cutout | SAM 3.1 | product found, 25.1% of the frame, transparent cutout produced |
| Studio shot | Muse Image | one scene generated; Muse Spark fidelity check: faithful, no differences |
| Campaign plan | Muse Wonder | planned headline and layout (`aiPlanned: true`); reel rendered by FFmpeg using the SAM cutout |
| Preflight, clean | exact rules + Muse Wonder | `ok: true`, no issues, Wonder fuzzy check ran |
| Edit price INR 129 -> 149 without regenerating | exact rules + Muse Wonder | blocked on **site, reel and caption**: expected INR 149.00, found INR 129.00 |

Enrichment (SAM + Image + fidelity) took about 53 s.
